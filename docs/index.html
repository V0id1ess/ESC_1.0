Getting Started

  1. Ensure the drone battery voltage is > 10.8V.
  2. Calibrate sensors using the ground station interface.
  3. Connect to the drone using QGroundControl.
  4. Plug in the Nomad module and PS4 controller into the computer.
  5. Initiate takeoff
  6. Monitor the live dashboard during the flight.
  7. Initiate landing and confirm a safe shutdown.
