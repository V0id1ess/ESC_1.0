Connection Issues

If the drone fails to connect, restart the ground station software and verify the wireless link. Ensure the drone is powered on and the correct communication port is selected.

Sensor Errors

  • Calibrate sensors again if values appear incorrect.
  • Confirm connectors are seated and there is no visible damage.
  • Check firmware version for compatibility with the sensor modules.

Flight Stability

If the drone is unstable or drifts, recalibrate the IMU and compass. Inspect propellers and motors, and adjust PID settings if necessary.

Data Logging Problems

When data is missing, verify the microSD card is installed correctly and formatted. Use the ground station log viewer to confirm file writes and check for storage capacity issues.
